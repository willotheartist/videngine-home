01

Read the source

Videngine loads the page in a real browser, takes the text, the images and the structured data, and throws away the navigation, the cookie banner and the footer.

02

Write the script

The source becomes a shot list with timings attached. You can accept it, edit a line, or hand Videngine your own script and skip this stage entirely.

03

Build the scenes

Each shot is a React component. Type, motion, safe areas and brand tokens are applied as code, so the hundredth video is laid out exactly like the first.

04

Record the voice

Synthetic narration by default, or upload your own audio. Captions are transcribed back from the finished track, so they match what was actually said.

05

Render and deliver

Frames render in parallel and combine into MP4 files. Review and download portrait and landscape versions from the studio.

A video editor gives you a canvas and expects taste. That is the right tool when the video is the point. It is the wrong tool when the video is a by-product of something else you already have: a listing, a catalogue, a changelog, a report.

Videngine treats a video as an artefact of its source. Approved scene rules can be reused when the source changes. Preserve the script, assets and settings when you want a revision to stay consistent with an earlier video.

It was built to feed one studio's own output, which means it was shaped by real deadlines rather than a feature roadmap. Everything in it earned its place by removing an evening of work.

Videngine is a programmatic video engine. You give it a source, such as a web page, a block of text or a row of data, and it returns a rendered MP4 with narration and captions. There is no timeline to edit and no manual export step. It is built for video that repeats, where the same template runs against changing data.
Most AI video generators create footage from a prompt, so the same prompt gives a different result each time. Videngine renders from templates written as code, so approved scene rules are applied consistently to source data. It uses AI to write the script and the voice track, not to invent the pictures. That makes it suitable for work where a wrong price or a garbled logo is not acceptable.
An editor is a canvas for one video at a time and rewards taste. Videngine is a pipeline for many videos and rewards structure. If you are making one hero film, use an editor. If you are making the same twenty-second video four hundred times with different data, an editor is the bottleneck.
A URL, plain text or markdown, a CSV, or a JSON payload. For batch work, one row becomes one video. Images are pulled from the source page or supplied alongside the data.
Yes. Typefaces, colours, logo placement, safe areas and motion are set once as tokens in the scene code, then applied to every render. Versioned templates help preserve those rules; new templates and unusual inputs still need review.
